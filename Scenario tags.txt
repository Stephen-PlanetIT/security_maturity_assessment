### Template Jinja2 Tag Reference Guide
To create your `planet_it_threat_template.docx` template, use the following variables:

#### Organisational Profile
* `{{ customer_name }}` — Name of the customer (e.g. Acme Corp)
* `{{ consultant_name }}` — Name of the consultant (e.g. Jane Doe)
* `{{ industry }}` — Industry segment
* `{{ users }}` — Total headcount
* `{{ endpoints }}` — Number of endpoints
* `{{ servers }}` — Number of servers
* `{{ operating_systems }}` — Operating systems in use
* `{{ cloud_env }}` — Cloud environments in use
* `{{ in_house_team }}` — Internal SOC team size/presence
* `{{ compliance }}` — Target compliance standards
* `{{ critical_infra }}` — Crown Jewels

#### Current Technology Stack
* `{{ mdr_provider }}` — Active MDR/SOC partner
* `{{ endpoint }}` — Endpoint security vendor
* `{{ endpoint_posture }}` — Endpoint capability licensing tier
* `{{ firewall }}` — Network firewall vendor
* `{{ identity }}` — Identity provider
* `{{ email }}` — Email security gateway
* `{{ m365_license }}` — Microsoft 365 licensing
* `{{ savviness }}` — Security culture profile

#### Operational Telemetry & Validation
* `{{ pentest_status }}` — Penetration testing frequency
* `{{ vuln_scanning }}` — Vulnerability scanning frequency
* `{{ remote_access }}` — Remote access strategy
* `{{ saas_backup }}` — M365/SaaS backup vendor
* `{{ ir_readiness }}` — Incident Response plan status
* `{{ mfa_status }}` — MFA enforcement level
* `{{ patching }}` — Patch management status
* `{{ backups }}` — Backup strategy details
* `{{ insurance }}` — Cyber insurance status
* `{{ rto }}` — Downtime tolerance (RTO)
* `{{ advanced_controls }}` — Pillar 3 advanced controls

#### Threat Simulation Content
* `{{ threat_narrative }}` — Detailed narrative story of the simulated attack.
* `{{ mdr_case_log }}` — Simulated MDR Case Log.
* **Attack Timeline Loop:**
  ```jinja
  {% for event in threat_timeline %}
  - [{{ event.timestamp }}] {{ event.event_description }}
  {% endfor %}
  ```
* **Strategic Advisory Recommendations Loop:**
  ```jinja
  {% for rec in recommendations %}
  - {{ rec }}
  {% endfor %}
  ```
